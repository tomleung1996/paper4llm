# Paper for LLMs 1.0.0

## English

Paper for LLMs 1.0.0 is the first stable public release.

### Highlights

- Convert supported ScienceDirect, Wiley Online Library, Nature, SpringerLink, and Science / AAAS article pages to structured Markdown.
- Preserve publisher-provided links between in-text citations and reference entries, with resolved and unresolved target reporting.
- Retain metadata, headings, paragraphs, lists, tables, formulas, figures, captions, footnotes, DOI links, and reference order where available.
- Copy the result or download a local `.md` file, with optional YAML metadata and image links.
- Use an English or Simplified Chinese interface automatically or through a persistent manual setting.
- Process article content locally without analytics, tracking, remote code, or developer-operated uploads.
- Release the source code under the MIT License.

### Install before the Chrome Web Store release

Download `paper4llm-1.0.0.zip`, unzip it, open `chrome://extensions/`, enable Developer mode, choose **Load unpacked**, and select the extracted directory.

The extension does not bypass publisher sign-in, institutional access, paywalls, or human-verification pages. Remote image links may still require the browser session that supplied access to the article.

## 简体中文

Paper for LLMs 1.0.0 是首个公开稳定版本。

### 主要功能

- 将受支持的 ScienceDirect、Wiley Online Library、Nature、SpringerLink 和 Science / AAAS 论文页面转换为结构化 Markdown。
- 保留出版商提供的文内引用与参考文献关联，并报告已映射和未映射的引用目标。
- 在页面提供相关内容时，保留元数据、标题层级、段落、列表、表格、公式、图片、图注、脚注、DOI 链接和参考文献顺序。
- 支持复制结果或下载本地 `.md` 文件，并可选择是否包含 YAML 元数据和图片链接。
- 自动使用英文或简体中文界面，也可以保存用户手动选择的语言。
- 论文内容仅在本地处理，不使用分析、追踪、远程代码或开发者运营的上传服务。
- 源代码依据 MIT 许可证发布。

### Chrome Web Store 上架前的安装方式

下载 `paper4llm-1.0.0.zip` 并解压，打开 `chrome://extensions/`，启用开发者模式，点击**加载已解压的扩展程序**，然后选择解压后的目录。

扩展不会绕过出版商登录、机构访问、付费墙或人机验证页面。远程图片链接仍可能依赖用于访问论文的浏览器会话。
