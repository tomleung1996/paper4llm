# Paper for LLMs 1.1.0

## English

- Added support for MDPI, Taylor & Francis, Frontiers, Oxford Academic, IEEE Xplore, Wolters Kluwer/Ovid, and SAGE Journals.
- Verified every new publisher with at least three open-access articles from different journals.
- Preserved publisher-provided citation targets, complete reference lists, figures, tables, formulas, and full author metadata when available.
- Added on-demand IEEE reference loading and structured Wolters Kluwer author extraction.

## 简体中文

- 新增 MDPI、Taylor & Francis、Frontiers、Oxford Academic、IEEE Xplore、Wolters Kluwer/Ovid 与 SAGE Journals 支持。
- 每家新增出版商均使用至少三篇来自不同期刊的开放获取论文进行验证。
- 尽可能保留出版商提供的文内引文目标、完整参考文献、图片、表格、公式与作者元数据。
- 新增 IEEE 参考文献按需加载和 Wolters Kluwer 结构化作者提取。
