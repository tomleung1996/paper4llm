# Paper for LLMs 1.3.0

## English

- Added full-text arXiv HTML support for modern and legacy arXiv identifier URLs.
- Preserved arXiv version and category metadata, complete author and affiliation lists, formulas, figures, tables, captions, footnotes, references, and citation links.
- Removed duplicated title/author content and bibliography back-reference controls, while preventing reference DOI values from being mistaken for the paper DOI.
- Verified the implementation with three open-access arXiv HTML papers from three research fields.

## 简体中文

- 新增 arXiv HTML 全文支持，兼容现代编号与旧式分类编号网址。
- 保留 arXiv 版本和分类元数据、完整作者与机构列表、公式、图片、表格、图注、脚注、参考文献及引文链接。
- 移除重复标题／作者内容和参考文献回链控件，并避免把参考文献 DOI 误认为论文本身的 DOI。
- 使用三个研究领域的三篇开放获取 arXiv HTML 论文完成验证。
